TOPPERG - TO-DO LIST (AI/DEVELOPER WORKING RULES)
==================================================
This file is instructions for whoever (or whatever AI) is doing the actual
build work on TopperG. Read this before starting ANY feature.

STANDING RULE (applies to every single task below)
--------------------------------------------------------
After finishing a feature:
  1. Re-read the FULL code of that feature (not just the new lines) -
     look for bugs, unhandled null/empty states, unfinished TODOs.
  2. Manually test it end-to-end with real data (not placeholder text).
  3. Fix anything broken before moving on - do not leave "fix later" bugs.
  4. Commit directly to GitHub (https://github.com/aalamdiwan555-art/TopperG)
     with a clear commit message describing exactly what changed.
  5. Update the relevant .txt document(s) in this doc set if actual
     behavior differs from what was originally planned (docs must always
     reflect real, current app behavior - not the original plan if it
     changed).
  6. Only then move to the next feature on this list.

Never mark a feature "done" just because it compiles. "Done" = tested with
real content + committed + docs updated.
